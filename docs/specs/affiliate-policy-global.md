# Global Affiliate Program — 운영 정책 비교 설계안

> BITE ME JAPAN 설계안은 "기능 구조/정책 항목을 파악하는 참고자료"로만 쓰고, 실제 Global 운영 정책은 **Shopify Collabs의 공식 정책·운영 방식**을 우선 참고해 새로 설계한다.
> 항목별로 ① JP 기존 정책 / ② Shopify Collabs 정책·운영 방식(공식 Help Center 기준, 출처는 문서 하단) / ③ Global BITE ME 적용 제안 / ④ 추가 결정 필요(TBD) 순으로 정리했다.
> 법률·세무 항목은 Collabs 공개 정보로 확인되는 범위와, 별도 법률/세무 검토가 필요한 범위를 명확히 나눴다 — 이 문서에서 세율·원천징수 여부·계약 법인을 임의로 확정하지 않았다.
> 작성 2026-09-18 · Issue #141 · [기술 설계안](affiliate-program-global.md)과 별도 문서, 구현 전 검토용

---

## 1. Affiliate 가입 및 자동 활성화 조건

- **① JP** — 팔로워 수 등 정량 조건 없음. 셀프 가입, 승인 단계 없음. LINE 로그인 + 18세 이상 확약 + 약관 동의만 요구.
- **② Collabs** — 두 트랙이 공존한다. **Open access**: 승인 없이 즉시 활성화되지만 "현재 미국·영국·캐나다 크리에이터만" 대상. **Invite-only**: 머천트가 개별 크리에이터를 선택해 초대 — 사실상 승인제다. 크리에이터는 한 시점에 프로그램 하나에만 속한다.
- **③ Global 제안** — 이미 PR #142 기술 설계안에서 확정한 "신청 즉시 자동 활성화, 관리자 개입 없음"을 유지한다. 이는 Collabs의 open-access 트랙과 같은 철학이다. 국가 제한은 Collabs와 달리 두지 않는 방향으로 제안(§12 참고). 18세 이상 확약·약관 동의는 JP 방식 유지.
- **④ TBD** — 없음(방향 확정). 국가 제한 여부만 §12에서 별도 결정.

## 2. 개인 Referral Link 발급 및 전환 귀속 방식

- **① JP** — 가입 즉시 전용 링크 발급, 카트 속성에 파트너 참조 한 줄을 추가해 주문까지 연결.
- **② Collabs** — 머천트가 URL 파라미터를 설정해 크리에이터별 고유 링크를 생성. 크리에이터가 다른 프로그램으로 이동해도 "링크와 할인 코드는 동일하게 유지"된다고 명시.
- **③ Global 제안** — JP 구조(가입 즉시 `biteme.one/a/{code}` 발급, 카트 속성 기록)를 유지. Collabs처럼 캠페인 이동 시에도 링크는 고정해 파트너가 이미 뿌린 링크가 끊기지 않게 한다.
- **④ TBD** — 없음.

## 3. Attribution window 및 중복 귀속 우선순위

- **① JP** — 코드 > 링크(클릭 후 30일) > 고객 로그인 매칭(30일) 3단 우선순위.
- **② Collabs** — 클릭 기반 쿠키 추적을 쓰는 것은 확인되나, **기본 attribution 일수와 코드·링크 동시 발생 시 우선순위 규칙은 공식 Help Center에 공개돼 있지 않다.** 업계 관행은 30/60/90일이지만 이는 Collabs 고유 수치가 아니라 일반 관행이므로 참고 수준으로만 취급.
- **③ Global 제안** — JP의 3단 구조(코드 > 링크 > 로그인 고객)를 그대로 채택 — 이 구조는 Collabs 공개 정보보다 오히려 더 정교하고, Shopify Customer Account 로그인을 이미 갖춘 Global 인프라에서 그대로 구현 가능한 Global만의 이점이다. 윈도우는 30일을 잠정 채택.
- **④ TBD** — 정확한 일수는 Global 실제 반품정책 확인 후 재검증. Collabs의 실제 기본값은 비공개라 참고 불가 — Global 자체 판단으로 결정해야 함.

## 4. 기본 Commission rate 및 캠페인별 별도 설정

- **① JP** — 기본 10% 고정, 캠페인 12~20%.
- **② Collabs** — 머천트가 프로그램·컬렉션 단위로 % 직접 설정. Invite 프로그램은 크리에이터별로 다른 요율 허용. **업계 표준/기본값을 Shopify가 정해주지 않고 전적으로 머천트 재량**이라는 점이 확인된 사실이다.
- **③ Global 제안** — 기본 10%로 우선 제안(JP와 동일, 업계에서도 흔한 기준선). 캠페인은 운영자가 대상·상품별로 자유롭게 설정 — Collabs의 "프로그램 단위 + 개별 크리에이터 커스텀" 유연성을 캠페인 구조로 흡수.
- **④ TBD** — 기본 10%가 Global 마진 구조에 맞는지 재무 확인 필요.

## 5. Discount code 운영 여부 및 캠페인별 선택 발급

- **① JP** — 기본 층엔 코드 없음, 캠페인에만 선택 발급. 고객당 1회 + 총 사용 횟수 상한 + 기간 종료.
- **② Collabs** — 링크와 할인 코드 둘 다 지원하되 **코드는 선택사항**(필수 아님). 그리고 **"discount leaks"(코드 유출)를 공식적으로 자동 이의제기(auto-dispute) 트리거 중 하나로 명시** — Shopify가 코드 유출을 위반 행위로 취급한다는 뜻이다.
- **③ Global 제안** — PR #142에서 이미 확정한 "기본 코드 없음"을 유지 — Collabs도 코드를 선택사항으로 두고 유출을 공식 위반 사유로 다룬다는 사실이 이 결정을 뒷받침한다. 캠페인 코드에는 Collabs처럼 "코드 유출 감지 시 자동 재검토/정지" 트리거를 §10(Fraud) 정책에 넣는다.
- **④ TBD** — 코드 유출을 어떤 방식(쿠폰 사이트 모니터링 서비스 vs 자체 스캔 스크립트)으로 감지할지.

## 6. 주문 취소/환불 시 Commission 처리

- **① JP** — 확정 전 환불이면 차감, 부분환불은 재계산(약관 제4조).
- **② Collabs** — "머천트가 보류기간(1~90일) 중 주문을 취소하거나 전액 환불하면 해당 커미션은 자동 취소된다." 부분환불에 대한 구체 규정은 공개 문서에 없고 "환불·취소에 따라 조정될 수 있다"는 원칙 문구만 있다.
- **③ Global 제안** — 확정 전 취소/전액환불 = 자동 커미션 취소(Collabs와 동일). 부분환불은 Collabs가 공개하지 않은 영역이므로 JP의 비례 재계산 규칙을 그대로 채택해 공백을 메운다.
- **④ TBD** — 확정 후(보류기간 종료 후) 뒤늦게 들어오는 환불 처리 방식 — Collabs도 명문화하지 않은 영역이라 Global 자체 정책이 필요하다.

## 7. Commission Pending → Confirmed 기준 및 보류 기간

- **① JP** — 주문일 + 30일. 일본 반품 정책(도착 후 7일) 대비 여유 있게 산정.
- **② Collabs** — 머천트가 **1~90일 사이에서 보류 기간을 직접 설정**(기본값 30일). 보류 기간 중 머천트가 의심 거래에 이의제기 가능, 미해결 상태로 30일이 지나면 연결이 자동 일시정지되고 해당 커미션은 취소된다.
- **③ Global 제안** — Collabs 기본값(30일)과 JP 값이 일치하므로 **30일을 기본으로 채택**하되, Collabs처럼 상품군별로 1~90일 범위에서 운영자가 조정 가능하게 여지를 둔다.
- **④ TBD** — Global 실제 반품정책 확인 후 30일이 최종적으로 맞는지 검증.

## 8. 정산 주기 및 Minimum payout

- **① JP** — 월 1회 익월 말 지급, 최소 ¥3,000, 미달분 이월.
- **② Collabs** — 크리에이터 쪽은 **자동 정산이 월 2회**, 잔액이 **최소 $25(USD)**에 도달해야 지급되며 Hyperwallet을 통해 지급된다. 단, Collabs는 "브랜드가 보류기간 종료 후 Shopify 청구서에 커미션이 반영되고, Shopify가 크리에이터에게 대신 지급"하는 **마켓플레이스형 정산 구조**다 — 브랜드가 크리에이터에게 직접 송금하지 않는다.
- **③ Global 제안** — Collabs의 마켓플레이스형 결제 인프라(Shopify가 중개)는 Global 자체 KV 원장 + 직접 지급 구조로 그대로 옮길 수 없다. **JP식 월 1회 정산 구조는 유지**하되, Collabs의 "최소 지급액" 개념을 스토어 통화 기준으로 도입해 소액 다건 지급의 운영 부담을 줄인다.
- **④ TBD** — 최소 지급액을 스토어 통화 기준 얼마로 할지, 월 1회를 Collabs처럼 월 2회로 늘릴지.

## 9. Self-referral / 본인 구매 처리

- **① JP** — 주문 고객의 LINE 계정·이메일이 파트너와 같으면 자기구매로 적재, 커미션만 0. 결제 자체는 막지 않음.
- **② Collabs** — **공식 Help Center 어디에도 self-referral을 명시적으로 금지하거나 처리하는 규정이 없다.** Community Guidelines는 "허위정보 제출 금지" 같은 일반 조항뿐이고, 본인 구매에 대한 구체 규칙은 공개돼 있지 않다 — 머천트가 개별적으로 관리해야 하는 영역으로 보인다.
- **③ Global 제안** — JP 규칙을 그대로 채택한다. Shopify Customer ID·이메일 매칭으로 자기구매를 감지하고, 결제는 허용하되 커미션만 0으로 처리 — Collabs가 이 부분을 공개하지 않으므로 참고할 표준이 없고, JP 규칙이 유일하게 구체적인 안이다.
- **④ TBD** — 없음(JP 방식 채택 제안).

## 10. 부정 클릭·부정 주문·쿠폰 사이트 등 Fraud 정책

- **① JP** — 자기구매·다계정 우회·코드유출·귀속유실·주문중복/유실·환불누락·코드충돌·계좌정보 8종 위험을 항목별로 통제.
- **② Collabs** — Community Guidelines에 일반 금지행위(허위정보 제출, 악성코드, 스팸/피싱, 명예훼손·외설 등, Shopify 평판 훼손 행위) 명시. 위반 시 **단계적 제재**: 커미션 0%로 조정 → 보류 중인 지급 취소 → 브랜드 연결 해제 → (중대 위반 시) 영구 차단("이 결정은 최종적이며 변경 불가"). 머천트 쪽 자동 이의제기(auto-dispute) 트리거로 **코드 유출, 무단 유료광고 집행, 의심스러운 SNS 활동**이 명시적으로 언급된다.
- **③ Global 제안** — JP의 8종 통제를 뼈대로 유지하되, Collabs가 명시한 추가 트리거 2가지(파트너의 무단 유료광고 집행, SNS 이상 활동 급증)를 관리자 화면의 이상 감지 항목에 추가한다.
- **④ TBD** — "무단 유료광고 집행"을 운영적으로 어떻게 확인할지(파트너 자진 신고 vs 광고 계정 모니터링 도구 도입).

## 11. Affiliate 계정 정지/종료 및 미확정 Commission 처리

- **① JP** — 파트너 셀프 탈퇴 버튼 제공. 정지 시 "위반 관련 성과분만" 불지급. 탈퇴 즉시 링크·코드 무효화.
- **② Collabs** — 위반 시 단계적 제재(§10 참고) — 최종 차단되면 **"모든 보류 중인 지급이 취소"**되고 이 결정은 번복 불가.
- **③ Global 제안** — 경미한 위반은 JP처럼 "위반 관련 건만 불지급"으로 비례 대응하고, 반복·중대 위반에서만 Collabs처럼 **보류 커미션 전액 취소 + 영구 차단**의 강한 제재를 적용하는 2단계 체계로 절충한다.
- **④ TBD** — "경미"와 "중대"를 가르는 구체 기준(예: 위반 횟수, 금액 규모).

## 12. 국가별 참여 제한

- **① JP** — 해당 없음(일본 단일 스토어).
- **② Collabs** — Open-access 프로그램은 **"현재 미국·영국·캐나다 크리에이터만"** 가입 가능하다고 공식 문서에 명시돼 있다. Invite 프로그램의 지역 범위는 공개돼 있지 않다. (참고: Collabs 자체가 한때 "신규 크리에이터 가입을 받지 않는다"는 공지를 낸 이력도 확인됨 — Collabs 정책 자체가 변동성이 있다는 뜻이므로 참고용으로만 취급.)
- **③ Global 제안** — Global몰은 다국가 대상이므로 Collabs와 달리 **원칙적으로 국가 제한을 두지 않는** 방향을 제안한다. 다만 지급 가능한 결제 수단이 없는 국가는 "가입·활동은 가능하되 지급 시점에 별도 안내"하는 식으로 예외 처리.
- **④ TBD** — 실제 지급 가능 국가 목록(결제·세무 인프라 기준으로 확정 필요).

## 13. 개인정보 처리 및 데이터 보관

- **① JP** — IP는 해시만 저장, 계좌정보는 초기 단계(가입·캠페인 참여)에서 수집하지 않음 — 개인식별정보 최소화 원칙.
- **② Collabs** — **공식 Help Center 문서에서 크리에이터 개인정보 처리·보관에 대한 Collabs 전용 조항은 확인되지 않았다.** Shopify 전체 개인정보처리방침에 포함되는 것으로 추정되나, Collabs만의 별도 규정은 공개돼 있지 않다.
- **③ Global 제안** — 참고할 Collabs 공개 기준이 없으므로, JP의 최소 수집 원칙(IP 해시, 계좌정보 후순위 수집)을 그대로 채택한다 — 현재로선 이것이 유일하게 구체적인 근거다.
- **④ TBD (법률 검토 필요)** — Global 대상 국가에 GDPR·CCPA 등 적용 규제가 있는지는 Collabs로도 JP로도 대신 확정할 수 없는 영역 — 별도 법률 검토 필수.

## 14. 세금 및 지급 관련 책임

- **① JP** — 원천징수 조항이 약관(제5조 3항)에 있으나 실제 적용은 별도 세무 확인 후 결정. 계약 법인은 株式会社インケア 기준.
- **② Collabs** — **"크리에이터가 자신의 세금 신고·납부 의무를 직접 책임진다"**고 명시. 미국 크리에이터는 연 $599.99 도달 시 W9 제출을 요구받고, 미제출 시 연간 지급액이 그 금액으로 제한된다. 그리고 **"Shopify는 일부 관할권에서 크리에이터 서비스 판매와 관련한 세금을 직접 징수·신고한다"**고 명시 — Collabs는 일부 지역에서 마켓플레이스 원천징수자 역할까지 겸한다.
- **③ Global 제안** — "크리에이터 본인이 세무 책임을 진다"는 원칙 문구는 Collabs를 참고해 채택할 수 있다. 다만 Shopify가 갖춘 마켓플레이스 세금 징수·신고 인프라를 Global이 자체 구축하는 것은 별개 프로젝트 규모의 일 — **이 부분은 Collabs를 그대로 따라갈 수 없는 구조적 한계**로 명시해 둔다.
- **④ TBD (법률·세무 검토 필수, 이 문서에서 확정하지 않음)** — 계약 법인 확정, 대상 국가별 원천징수 의무 여부, "$599.99류" 신고 임계값을 Global의 어느 국가 기준으로 적용할지. **이 항목 전체는 Collabs 공개 정보로 대체할 수 없고, 세무사·법무 검토 없이 이 문서 단계에서 임의로 확정하지 않는다.**

---

## 요약 — Global이 Collabs와 구조적으로 다시 정면 참고할 수 없는 지점

1. **정산 구조** — Collabs는 Shopify가 중개하는 마켓플레이스형 결제(브랜드→Shopify 청구, Shopify→크리에이터 지급)라 Global의 직접 지급 구조와 근본적으로 다르다. 참고는 "최소 지급액", "보류기간 범위" 같은 수치 개념까지만 가능.
2. **세금 인프라** — Collabs는 일부 관할권에서 세금을 직접 징수·신고하는 마켓플레이스 세무 기능을 가진다. Global은 이 인프라가 없으므로 별도 법률/세무 검토로 채워야 한다.
3. **Self-referral·개인정보** — Collabs 공식 문서에 공개된 규정이 없어 JP 원안이 사실상 유일한 참고 기준이 됐다.
